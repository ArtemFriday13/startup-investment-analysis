# Анализ инвестиций в стартапы

## Описание проекта
Проект посвящён анализу данных о стартапах, раундах финансирования и возврате инвестиций.

## Цель
Исследовать структуру и динамику финансирования стартапов, выявить ключевые закономерности и сформулировать рекомендации.

## Используемые инструменты
- Python
- pandas
- numpy
- matplotlib
- seaborn
- Jupyter Notebook

## Что сделано
- выполнена предобработка данных
- обработаны пропуски и типы данных
- проанализированы объёмы инвестиций
- исследована динамика финансирования по годам
- сформулированы выводы и рекомендации

## Данные
Данные использованы в рамках учебного проекта и не публикуются.

Для запуска проекта необходимо добавить файлы:
- `cb_investments.csv`
- `cb_returns.csv`

## Файл проекта
- `startup-investment-analysis.ipynb`
